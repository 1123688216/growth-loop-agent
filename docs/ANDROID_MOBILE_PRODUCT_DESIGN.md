# 成长回路 Android 移动端产品设计 v2

## 1. 重新定义产品

Android 端不是网页的缩小版，而是一个随身的“下一步教练”：用户打开应用后，先看到今天最值得推进的一步；想记录时只需要点一次“记录”，白天不被问题打断，AI 在晚报里把当天记录合并后统一追问、评分，最后收束成经验。

移动端的北极星路径是：

`打开应用 → 看下一步 → 随手记录 → 晚报统一回顾 → 完成明天的一步`

## 2. 设计方向

- 目标用户：在碎片时间里学习、工作、运动和恢复的个人用户，主要用单手完成操作。
- 气质：安静、温暖、果断；像一个真正的手机伴侣，而不是缩小后的网页工作台。
- 布局：全屏单列内容，深色原生感顶栏、底部四项主导航、右下角无文字圆形记录按钮；页面只在自己的滚动容器内移动。
- 字体：正文和控件使用高可读无衬线字体，关键句使用少量衬线字体；正文最小字号 10–12px，主要触点不低于 44px。
- 色彩：墨绿色作为应用骨架，荧光浅绿表示可执行动作，珊瑚色表示正在发生，鼠尾草绿表示恢复与完成。
- 动效：只使用 160–240ms 的按压、底部抽屉、进度环和状态切换动画；支持 `prefers-reduced-motion`。
- 记忆点：每次打开都出现“下一步行动”深色卡片和环形今日进度；晚报用月相条提示节奏，形成独立于桌面 Web 的移动识别。

## 3. 信息架构

### 今日

1. 深色状态栏：成长回路、连续行动天数、头像。
2. 今日欢迎：日期、两行目标句和环形完成度。
3. 下一步行动：墨绿色大卡片，放入当前任务、时长、行动类型和主要开始按钮。
4. AI 记录舱：短文本记录框、字符计数、发送按钮和学习/运动/生活快捷提示。
5. 晚报月相条：白天只保存记录，21:30 按偏好把当天内容合并成一组问题。
6. 接下来：只展示眼前三件事，剩余任务进入路线页。
7. 番茄钟：作为低优先级节奏工具收在底部，不抢主任务焦点。

### 计划

- 一张主目标卡：目标描述、进度和时间范围。
- 一张 AI Agent 路线卡：理解问题 → 连接工具 → 验证迭代。
- 今日时间轴：每条任务支持 44px 以上的完成触点，并用颜色区分学习、运动、生活、休息。

### 记录

- 顶部“刚刚发生了什么？”入口，点击后打开全宽底部抽屉。
- 三个轻量统计：本周记录、理解记录、获得 XP。
- 时间线：每条记录显示主题、自然标签、奖励和时间；深度理解题从记录页按需进入，不在移动首页堆叠。

### 成长

- 等级卡：等级、角色、升级进度。
- 四项指标：有效行动日、本周投入、掌握证据、成长积分。
- 7 天节奏图和 AI 观察；不引入公开排名，也不把用户压缩成单一分数。

## 4. 关键交互规则

- 所有主要触点最小 44×44px；右下角记录按钮为 56px，使用无文字圆形动作按钮，适合单手操作。
- 记录入口不跳转新页面：主页面直接输入，浮动按钮打开底部记录抽屉。
- 抽屉只保留一个自由记录框：学习、运动、生活和休息都可以写；晚报再统一追问，不在白天强行拆分字段。
- 底部导航固定在安全区上方；内容滚动不会把导航推走，页面不产生横向滚动。
- Android WebView 的返回/重载不改变数据语义；记录和测验仍沿用现有 localStorage 原型账本，服务端持久化留到 MVP。
- Android 端只在需要时显示 AI：白天负责收好记录，晚间按偏好统一回顾，不主动堆叠复杂图表。

## 5. 技术落地

- `app/mobile-shell.tsx`：Android/Android WebView/窄屏浏览器使用的独立移动 UI v3。
- `app/page.tsx`：通过 Capacitor 平台、Android WebView UA 或 820px 以下视口选择移动壳；桌面 Web 继续使用原工作台。
- `app/globals.css`：移动 v3 的安全区、深色顶栏、进度环、底部导航、浮动按钮、底部抽屉、卡片和触控状态。
- Capacitor 继续复用 Next.js Agent、测验和微信接口；APK 后端地址仍为模拟器专用的 `10.0.2.2:3000`。

## 6. 本轮验收标准

- Android APK 不再渲染桌面侧栏、右侧栏或桌面 Hero；必须出现深色顶栏、环形今日进度、下一步行动卡、底部导航和无文字记录按钮。
- 412×867 模拟器下，`.app-mobile-v3` 为根壳，`body/document` 宽度等于视口宽度；内容在独立滚动容器内，不拉长系统页面。
- 今日、计划、记录、成长四个 Tab 可切换；记录抽屉只有一个文本框；计划路线、成长节奏图、晚报提示和任务完成均可操作。
- `npm.cmd run typecheck`、`npm.cmd run lint`、`npm.cmd run build`、`npm.cmd run android:debug` 通过，ADB 可见 `com.growthloop.agent/.MainActivity`，logcat 无 fatal/Chromium/JS 错误。

## 7. 暂不纳入

- 不在本轮复制原生日历、通知中心或完整设置页。
- 不把 localStorage 原型冒充成多设备同步；正式发布前仍需数据库、账号、推送授权和 release 签名。
